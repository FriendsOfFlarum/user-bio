# User Bio by dcorlette

A [Flarum](http://flarum.org) extension. Add a user's students to profile page.

### Installation

Install manually with composer:

```sh
composer require dcorlette13/flarum-userinfo:"*"
```

### Updating

```sh
composer update flarum-userinfo
```
